# prayority-legal

Public legal pages for the **Prayority** iOS app (App Store), served via GitHub Pages.

- **Privacy Policy** (ES + EN): [`/privacy/`](privacy/index.html)
- **Terms of Use** (ES + EN, includes Apple's minimum EULA terms): [`/terms/`](terms/index.html)

Live URLs:
- `https://varchenberg.github.io/prayority-legal/privacy/`
- `https://varchenberg.github.io/prayority-legal/terms/`

In App Store Connect, set the custom License Agreement (EULA) to the Terms URL instead of Apple's Standard EULA.

This repository contains only static HTML legal documents. It does **not** contain app source code.
