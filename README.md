# prayority-legal

Public legal pages for the **Prayority** iOS app (App Store), served via GitHub Pages.

- **Privacy Policy** (ES + EN): [`/privacy/`](privacy/index.html)
- Terms of Use: Apple Standard EULA (linked in-app), not hosted here.

Live URL: `https://varchenberg.github.io/prayority-legal/privacy/`

This repository contains only static HTML legal documents. It does **not** contain app source code.
